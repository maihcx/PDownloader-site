# Install PDownloader

## Before you begin

PDownloader is intended for 64-bit Windows 10 or later. Download installers only from the project's official GitHub releases.

## Installation steps

1. Open the [latest PDownloader release](https://github.com/maihcx/PDownloader/releases/latest).
2. Download the Windows installer attached to that release.
3. Close an older PDownloader instance if it is currently running.
4. Run the installer and review the destination and shortcut options.
5. Start PDownloader once so its local components can initialize.

## After installation

Open the main window and confirm that it starts normally. You can paste a direct URL into PDownloader immediately; browser capture is enabled separately through the [browser extension guide](?doc=browser-extension).

If Windows displays a security prompt, verify that the file came from the official release page before continuing.
