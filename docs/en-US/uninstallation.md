# Uninstall PDownloader

## Remove the browser extension

Open your browser's extension manager, locate PDownloader, and choose **Remove**. Repeat this in every browser profile where the extension was installed.

## Remove the Windows application

1. Close PDownloader and any active transfer windows.
2. Open **Settings → Apps → Installed apps** in Windows.
3. Find PDownloader and select **Uninstall**.
4. Follow the uninstaller until it confirms completion.

Removing the desktop application does not automatically remove a store-installed browser extension. Keeping these two actions separate lets users uninstall or reinstall either part independently.

Before deleting remaining download data, check whether unfinished tasks or completed files are still needed.
